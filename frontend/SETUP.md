# Setup

Quick start for CycleSafe. For the full story — why each pin exists, what each build failure means — see [README.md](./README.md).

## Prerequisites

| | |
|---|---|
| Node | 20+ (developed on 26) |
| npm | 10+ |
| Xcode | for iOS — install a simulator runtime via Xcode → Settings → Platforms |
| CocoaPods | `brew install cocoapods` — **not** `gem install`, system Ruby 2.6 is too old |

Web-only work needs just Node and npm.

## 1. Install

```bash
cd frontend
npm install
```

## 2. Run

### Web — fastest way in

```bash
npm run web
```

No native build, instant reload. Good enough for most UI work.

### iOS — primary target

```bash
npx expo run:ios                          # build + launch simulator
npx expo run:ios --device "iPhone 17 Pro" # pick a specific one
```

First build takes several minutes. After that:

```bash
npm start   # then press i
```

**Expo Go will not work.** The map uses native code Expo Go does not bundle; it crashes on launch with `TurboModuleRegistry.getEnforcing('MLRNCameraModule')`. `npm start` already targets the dev build (`--dev-client`) — if a header ever says `› Using Expo Go`, press `s` to switch.

### Android

Untested — no SDK on the dev machine. `npx expo run:android` should work in principle.

## 3. Verify

```bash
npm test          # 95 tests
npx tsc --noEmit  # typecheck
```

## If the iOS build fails

Two known failures, both covered in depth in the README:

**`resource fork, Finder information, or similar detritus not allowed`** — iCloud tags files with extended attributes and `codesign` refuses them. Search the build log for `CodeSign failed`, not the first error.

```bash
xattr -cr node_modules/expo-modules-jsi/apple

A=node_modules/expo-modules-jsi/apple
rm -rf "$A/.DerivedData"
mkdir -p ~/Library/Caches/expo-modules-jsi-derived
ln -s ~/Library/Caches/expo-modules-jsi-derived "$A/.DerivedData"
```

`npm install` wipes that symlink — re-run these lines if the error returns.

**`no member named 'executeSync' in 'worklets::WorkletRuntime'`** — wrong `react-native-worklets` resolved.

```bash
npx expo install react-native-reanimated react-native-worklets
npm ls react-native-worklets   # must not print "invalid"
```

## Where things live

```
app/            screens (Expo Router file-based routes)
src/theme/      design tokens — never hardcode a hex or radius
src/data/       domain types + fixtures
src/lib/        pure logic: geo gating, time windows, hazard scoring
src/map/        platform-split map behind one props interface
src/components/ UI primitives
```

`ios/` and `android/` are generated by prebuild and gitignored — edit `app.json` and re-run instead.
